# Menú Diario

App instalable para armar desayuno, comida y cena con un presupuesto en pesos y la lista de compra para supermercados de México.

La comida incluye postre y bebida (agua de sabor o refresco). Las cantidades cubren los días y las personas que elijas.

Los precios de anaquel, cuando existen, salen de [Open Prices](https://prices.openfoodfacts.org) y [Open Food Facts](https://world.openfoodfacts.org) (ODbL). Las recetas abiertas de referencia salen de TheMealDB. El presupuesto se queda en el teléfono.
